Create and Activate a Virtual Environment

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
In Backend
```bash
cd backend
py manage.py makemigrations
py manage.py migrate
py manage.py runserver
```
In Frontend
```bash
cd frontend
npm i
npm run dev
```
